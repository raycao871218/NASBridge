# 鸟巢

The management UI is named **鸟巢**; its Android companion is **麻雀会**. Both follow **咕咕咕**'s warm crayon-paper visual style.

`app/static/crayon.css` supplies the paper texture, irregular card outlines, dusty-blue controls, peach selection, coral heading marks, accessible focus states, and responsive treatment. `nest.svg` is the original hand-drawn vector bird-and-nest mark and favicon. Shared colors: paper `#FCF6E8`, card `#FFFCF4`, ink `#3B3A49`, muted text `#706B75`, blue pigment `#BACCEB`, peach `#F0C8AA`, coral `#D48D79`.

The API service identity, deployment paths, and configuration identifiers stay `NASBridge` for compatibility with existing clients. UI naming does not require migration of stored data.
